# Security Policy

## Supported Versions

Currently, only version `v1` of this project receives security updates and fixes.

| Version | Supported |
| ------- | --------- |
| v1      | ✅         |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately.

Do not open a public issue with vulnerability details, as this may expose the problem before it can be reviewed and fixed.

When reporting a vulnerability, include as much information as possible, such as:

* a clear description of the issue;
* steps to reproduce;
* potential impact;
* affected files, endpoints, or features;
* suggested fixes, if available.

After receiving the report, the vulnerability will be reviewed as soon as possible. If the issue is confirmed, a fix will be prepared for the supported version of the project.

## Scope

This policy applies only to version `v1` of this project.

Older versions, forks, or unofficial modifications are not covered by this security policy.

## Disclosure

Please do not publicly disclose the vulnerability until a fix is available or until the project maintainers have approved disclosure.
